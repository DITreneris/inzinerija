# DATA_AGENT: Svarbūs duomenys ir atnaujinimo periodiškumas

> Kurie duomenų failai reikalauja DATA_AGENT dėmesio bėgant laikui, kodėl ir kaip dažnai juos tikrinti/atnaujinti.

**Architektūra A:** `modules.json`, `glossary.json`, `tools.json` ir `tools-en.json` yra full redagavimo SOT (tools – LT+EN twin). **Build/runtime profiliai** generuojami iš full SOT per `npm run generate:core-data` (`scripts/generate-core-data.mjs`):

| Profilis                | Failai                                                         | Build flag                                               | Kada sync                           |
| ----------------------- | -------------------------------------------------------------- | -------------------------------------------------------- | ----------------------------------- |
| **MVP 1–6**             | `*-m1-m6.json`                                                 | `VITE_MVP_MODE=1`                                        | Keitimas liečia `id/moduleId <= 6`  |
| **Korporatyvinis 1–9**  | `*-m1-m9.json`                                                 | `VITE_MAX_BUILD_MODULE=9` (`npm run build:corporate`)    | Keitimas liečia `id/moduleId <= 9`  |
| **Corporate12 1–12**    | `*-m1-m12.json`                                                | `VITE_MAX_BUILD_MODULE=12` (`npm run build:corporate12`) | Keitimas liečia `id/moduleId <= 12` |
| **Corporate15 1–15**    | `*-m1-m15.json`                                                | `VITE_MAX_BUILD_MODULE=15` (`npm run build:corporate15`) | Keitimas liečia `id/moduleId <= 15` |
| **Full katalogas 1–18** | `modules.json`, `glossary.json`, `tools.json`, `tools-en.json` | full build (be MAX_BUILD)                                | Visada authoring SOT (M16–18 incl.) |

**M10–12 taisyklė:** keitimai moduliuose 10–12 → full SOT + EN overlay (`modules-en-m10-m12.json`) + `generate:core-data` (atnaujina `*-m1-m12` + `*-m1-m15`). **Nereikalauja** `*-m1-m6` / `*-m1-m9` sync.  
**M13–15 taisyklė:** keitimai → full SOT + EN overlay (`modules-en-m13-m15.json`) + `generate:core-data` (atnaujina `*-m1-m15.json`). Corporate12 slice M13+ neįtraukia.  
**M16–18 taisyklė:** keitimai → full SOT + EN overlay (`modules-en-m16-m18.json` via `build:modules-en-m16-m18`). **Ne** `generate:core-data` / core spill. Corporate18 = Wave D3.

## Agent contract (EN)

- **Role:** Sync JSON with content SOT; validate schema; resolve Architecture A full vs m1-m6 / m1-m9 / m1-m12 / m1-m15.
- **Does NOT:** Copy writing, React render.
- **Trigger:** `src/data/*.json`, `hallucinationRates.ts`, `npm run validate:schema`.
- **Skill:** `.cursor/skills/data-agent/`
- **Handoff:** → CODING_AGENT if new slide type; else CODE_REVIEW_AGENT.
- **Registry:** `AGENTS.md` §Agents.

## 6. Schemų skaidrės ir duomenys (geriausios praktikos)

Kai skaidrėje naudojamas **blokas su diagrama** (pvz. `blockLlmAutoregressive`, Schema3, RlProcess), **duomenų tiesa** – `modules.json` (kuris modulio skaidrėje rodomas kuris blokas, `section.image` arba atitinkamas block tipas). **Geometrijos ir vizualinės tiesos** – SCHEME_AGENT ir layout failai (pvz. `llmAutoregressiveLayout.ts`, `schema3Layout.ts`), ne JSON.

**DATA_AGENT atsakomybė schemoms:**

- Nesikeičia diagramų koordinatės, viewBox, blokų pločiai/auščiai – tai SCHEME_AGENT (žr. `docs/development/SCHEME_AGENT.md`).
- Jei keičiasi **tekstas diagramoje** (žingsnių pavadinimai, pavyzdžio etiketės) ir jie saugomi JSON – DATA_AGENT sinchronizuoja su turinio SOT; jei tekstas hardcodintas layout/diagram komponente – CONTENT_AGENT / CODING_AGENT.

**Schemų skaidrėse – kas keičia ką:** Turinys (tekstai, žingsnių pavadinimai), saugomas JSON arba skaidrės body – sinchronizuoja **DATA_AGENT** su turinio SOT. Geometrija (koordinatės, viewBox, blokų matmenys, rodyklės) – **SCHEME_AGENT**; layout failai nepriklauso nuo modules.json. **Image key** (`sections[].image`) – DATA_AGENT deda į `modules.json` + EN overlay **tik po** registry įrašo (M7–12: `DIAGRAMU_M7_M12_REGISTRY.md`; M13–15: `DIAGRAMU_M13_M15_REGISTRY.md`). Diagramų labelių TS failai (`m13*Content.ts` ir pan.) – ne DATA_AGENT JSON. Pilnas atsakomybių skirtynas: `docs/development/DIAGRAMU_GERIAUSIOS_PRAKTIKOS.md`, `docs/development/SCHEME_AGENT.md` §2.1 / §2.2b.

**Schemų geriausios praktikos (tikrinimui):** Centravimas viewBox (START_X taip, kad turinys būtų horizontaliai centre), teksto telpimas į blokus (tspan laužymas, PAD_TOP/LINE_HEIGHT), lygmenų tarpai (didesnis tarpas tarp eilučių), vertikalus grid bloke (32/24/16px). Pilnas sąrašas: `docs/development/SCHEME_AGENT.md` §3, `docs/development/LLM_DIAGRAMOS_VIZUALUS_VERTINIMAS.md`.
