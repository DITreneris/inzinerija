# M7–M12 schemų registry

> Tikslas: viena prižiūrima vieta M7–M12 schemų routing, interaktyvumo, layout SOT ir testų būsenai. Naujos schemos turi būti planuojamos per šį registry prieš keičiant `modules.json` arba React komponentus.
>
> **Master indeksas:** [`TEACHING_ELEMENTS_REGISTRY.md`](TEACHING_ELEMENTS_REGISTRY.md) + [`teaching-elements-overlay.json`](teaching-elements-overlay.json). Slide ID čia = live `modules.json` (2026-07-24 sync).

## Image key policy

- Nauji `sections[].image` raktai turi būti semantiniai: `m7_*`, `m9_*`, `m10_*`, `m12_*`.
- Legacy SVG keliai (`/da_pipeline_6.svg`, `/da_bi_schema_4.svg`) lieka palaikomi per `diagramRenderers.tsx` alias, bet naujiems įrašams nenaudojami.
- Jei schema moko procesą, žingsnius arba turi LT/EN tekstus, ji turi būti React komponentas (dažnai per `EnlargeableDiagram` kaip **mobile** scroll/reflow frame); desktop enlarge/modal **neprivalomas** ir default OFF (`showEnlargeControl=false`). Statinis assetas tinka tik iliustracijai.
- Interaktyvi schema turi naudoti `InteractiveDiagramShell` ir `DiagramStepNav`; SVG hit zonos yra tik pointer-only per `DiagramStepHitArea`.

## Santykis su M1–M9 auditu

M7–M9 etalonas ir vizualinis smoke backlog'as aprašytas `docs/development/DIAGRAMU_M1_M9_AUDITAS.md`. Šis registry yra aktyvus M7–M12 routing, test coverage ir naujų `sections[].image` raktų pratęsimas; naujos M10+ schemos registruojamos čia (ir master overlay) prieš keičiant `modules.json`.

**Kokybės auditas / ROI eilė (M7–M9):** [`M7_M9_SCHEME_AUDIT.md`](M7_M9_SCHEME_AUDIT.md) – 18 elementų, 4 FAIL (`preCopyCheckBlock`, M8/80 test-scope, `toolChoiceBar` default ×9, `m9_data_workflow`), batch'ai `M79-S0`…`S6`. Prieš M7–M9 schemos keitimą perskaityti §5 sisteminius radinius (compact tipografijos grindys; HTML kortelių keyboard kontraktas; formos individualumas 73 vs 89).

## Priėmimo vartai

1. Master overlay + šio registry eilutė atnaujinta prieš pridedant arba keičiant `sections[].image` raktą.
2. `diagramRenderers.tsx` turi React rendererį visiems procesiniams M7–M12 `image` raktams.
3. Interaktyvios schemos turi testą, kuris tikrina `nav button` skaičių ir kad SVG neturi `role="button"` / `tabIndex`.
   3b. **HTML kortelių diagramos** (`M9DataWorkflowDiagram`, `HallucinationPipelineDiagram`, `StrukturuotasProcesasDiagram`): kortelės = pointer activate + `tabIndex={-1}` + `aria-hidden` (Shell nav = keyboard primary, `DIAGRAM_KIT_STANDARD` HTML checklist). Vartas #3 skenuoja tik `svg [role="button"]`, todėl HTML kortelės **turi** atskirą guard testą, kad nesusidarytų dubliuotas tab kelias. Žr. `M7_M9_SCHEME_AUDIT` §5.2.
4. Dark mode patikra turi įrodyti, kad schema naudoja tamsų SVG foną arba sąmoningai dokumentuotą išimtį.
5. M7–M9 core profiliai sinchronizuojami per `npm run generate:core-data`, jei normalizuojami full SOT `image` raktai.
6. `npm run audit:teaching-elements --strict` – exit 0.
